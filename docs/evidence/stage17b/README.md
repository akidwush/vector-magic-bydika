# Stage 1.7B actual export evidence

These SVG files are byte-for-byte copies of real browser application downloads,
not manually edited reconstructions. Screenshots show identical source coordinates
and scale at 100/400/1000%; source raster pixels use nearest-neighbor display,
while SVGs render as vectors. All pictured artwork is original CC0-1.0 from the
Stage 1.7A/B corpora. This dedication applies to artwork only.

A-auto and thin-negative use the unchanged Auto controls; P/Q explicitly use
the existing planar profile. Orbital Auto is unchanged; the planar probe is post
hoc and does not demonstrate improved Auto routing. Unchanged small-symbols,
signage and pale-garden files are retained as failures. Rejected full-model
leaf evidence is labelled separately. See the report for all gates/limitations.
